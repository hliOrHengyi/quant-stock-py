一、项目简介
------------------------------------------------------------------
本系统基于通达信(TDX)本地数据，利用 Python 解析通达信公式语言，
实现"板块筛选 -> 个股筛选"的自动化选股流程，并输出可导入通达信的
.blk 板块文件和详细的个股分析报告。

二、运行环境
------------------------------------------------------------------
1. Python 3.8+ (推荐 3.10+)
2. 依赖库: pandas, numpy     安装: pip install pandas numpy
3. 通达信安装在 C:\通达信，须包含完整的日线数据
   SH 日线: C:\通达信\vipdoc\sh\lday
   SZ 日线: C:\通达信\vipdoc\sz\lday

三、快速开始
------------------------------------------------------------------
打开终端 (PowerShell 或 cmd)，进入项目目录：
    cd D:\Code\quant-stock-py
执行：
    py -3 main.py
即可按"板块筛选 -> 收集成分股 -> 个股筛选"流程完整跑一遍。
首次运行约需 2-3 分钟，后续运行可缓存板块指数列表。

四、命令参数
------------------------------------------------------------------
  main.py                          完整选股(板块+个股)
  main.py -q                       静默模式
  main.py --no-industry            跳过板块筛选，直接全市场
  main.py --no-stock               只做板块，不选个股
  main.py --no-export              不导出 .blk
  main.py --no-report              不导出报告
  main.py --list-industries        列出板块指数
  main.py --test-stock 600519      测试单只股票
  main.py --test-industry 881319   测试板块指数
  main.py -if 板块选择.txt          指定板块公式
  main.py -sf 个股选股.txt          指定个股公式
  main.py -o 个股选股.blk           指定输出文件名

五、公式编写说明
------------------------------------------------------------------
公式使用通达信公式语法，输出信号变量名为 XG：
  板块选择.txt  >> 筛选板块指数
  个股选股.txt  >> 筛选个股

常用函数:
  REF(X,N)     MA(X,N)     CROSS(A,B)     COUNT(X,N)
  SUM(X,N)     HHV(X,N)    LLV(X,N)       EMA(X,N)
  ABS(X)       MAX(A,B)    MIN(A,B)       IF(C,A,B)
  BETWEEN(A,B,C)            EXIST(X,N)    FILTER(X,N)

行情字段别名: O/OPEN  H/HIGH  L/LOW  C/CLOSE  V/VOLUME  AMOUNT
运算符: +  -  *  /  >  <  >=  <=  =  <>  AND  OR

公式示例:
  DIF := EMA(CLOSE,12) - EMA(CLOSE,26);
  DEA := EMA(DIF,9);
  MACD := 2*(DIF-DEA);
  XG: DIF>0 AND C>MA(C,20);

六、输出文件
------------------------------------------------------------------
运行后生成 (以 23062026 为例)：

1. 23062026个股.blk
   > 复制到 C:\通达信\T0002\blocknew\ 即可在通达信查看
   > 格式: 市场前缀(1位)+6位代码=7位 例: 002522 / 1603120

2. 23062026板块.blk
   > 选中板块指数，格式: 1+6位板块代码 例: 1880646

3. 23062026选股详情.txt
   > 每股的代码/名称/价格/概念/命中原因详细分析

4. 选股报告.txt
   > 选股概况汇总

七、常见问题
------------------------------------------------------------------
Q: py 不是内部或外部命令?   A: 安装 Python 并加入 PATH
Q: 导入报错?                 A: pip install pandas numpy
Q: 结果和通达信不同?          A: 本地 .day 数据 vs 实时行情，差异正常
Q: 函数不全?                 A: 可修改 formula/functions.py 添加
Q: 修改选股公式?             A: 编辑 板块选择.txt / 个股选股.txt
Q: 跑一次多久?               A: 约 2-3 分钟 (I/O 为主)
Q: 北交所支持?               A: 已包含，需配置日线目录
